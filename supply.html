BOM CSV checker

Demo

Upload or paste a bill of materials. The file is read in this browser and never uploaded. The sample is made-up demo data, not a real company's suppliers.

Two boxes, two file formats. This checker takes part_number, description, qty, supplier, with optional alt_suppliers, alt_qualified, lead_time_days, on_hand_days, unit_cost_usd (times in days), and scores which part is most likely to block a build. "Use your own data" at the top of the page takes part, category, lead_time_weeks (times in weeks), the same file as POST /api/v1/supply, and shows which parts will run short against the public research. Each box tells you if you load the other one's file.
